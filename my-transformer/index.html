CORPUS BASICS

什么是 N-gram？

N-gram 是语料中连续 N 个 Token 组成的片段。这个演示会根据前文，统计语料里哪些 Token 曾经接着出现，作为下一步的候选。

  • 优先参考前面 2 个 Token（3-gram）；没有匹配时退回前面 1 个 Token（2-gram）。
  • 仍没有匹配时，使用语料中的单 Token 频率（1-gram）。

候选再结合出现频率与注意力相似度计算融合分数，并按温度进行选择。这是教学用模拟，不是实际大模型推理。
