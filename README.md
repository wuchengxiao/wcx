# wcx

> 功能模块中心 · 在线工具集合

这是一个基于 HTML / CSS / JavaScript 的前端工具集仓库，集合了多个实用型在线工具与演示模块，覆盖 AI 对话、文档处理、JSON 格式化、Markdown 编辑、Excel 处理、日志查看、白板、图片管理等场景。

本仓库以静态网站的方式组织，适合直接部署到 GitHub Pages、静态托管平台或本地前端环境使用。

## 项目简介

本项目的入口页面是 `index.html`，首页以“功能模块中心”的方式展示多个模块入口，用户可以直接点击进入不同功能模块。项目内容以小工具类页面为主，典型特点包括：

- 轻量、无需后端
- 适合静态部署
- 多功能入口集中展示
- 可扩展的前端模块结构
- 适合作为个人工具箱 / 学习 demo / 前端实验场地
